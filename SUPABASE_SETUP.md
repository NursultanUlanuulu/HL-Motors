# Подключение Supabase

Код готов к подключению. Пока в `.env.local` не указаны параметры Supabase, приложение продолжает работать с localStorage и IndexedDB. Настоящая база не создана этим изменением.

## 1. Создать проект

1. Откройте https://supabase.com/dashboard и создайте проект `motors`.
2. Сохраните пароль базы в менеджере паролей. Для приложения ниже используется API-ключ, а не пароль базы.
3. Выберите регион размещения с учётом аудитории. Перед запуском проверьте сайт и загрузку файлов с реального подключения администратора в Китае: доступность из Китая пока не проверена.
4. Дождитесь завершения создания проекта.

## 2. Создать таблицы и хранилище

В **SQL Editor → New query** вставьте содержимое `supabase/migrations/202609140001_catalog.sql` и выполните запрос.

Создаются:

- `vehicles`: идентификатор, JSONB-документ со всеми полями и двумя языками, версия для защиты от одновременного редактирования, даты.
- `site_settings`: контакты сайта.
- Публичное хранилище `vehicle-media`: JPG, PNG, WebP, AVIF, MP4, WebM, MOV. Фото до 15 МБ, видео до 50 МБ. Проверьте, что общий лимит Storage в проекте разрешает 50 МБ; лимиты и квоты зависят от тарифа.

Таблицы закрыты для `anon` и `authenticated`. Доступ идёт через сервер Next.js; запись требует существующую сессию единственного администратора. Supabase Auth не требуется. Бакет публичный, потому что фотографии и видео показываются посетителям сайта. Загрузку разрешает только сервер после проверки сессии.

## 3. Добавить настройки

Скопируйте `.env.example` в `.env.local` и заполните:

```dotenv
SUPABASE_URL=https://PROJECT_REF.supabase.co
SUPABASE_SECRET_KEY=sb_secret_...
ADMIN_SESSION_SECRET=случайная_строка_не_короче_32_символов
ADMIN_PASSWORD=ваш_пароль_администратора
```

Project URL находится в окне **Connect** / настройках проекта. Серверный ключ — **Settings → API Keys → Secret keys**. Используйте новый Secret key, не Publishable key. Ключи не отправляйте в чат и не коммитьте. `.env.local` уже исключён из Git.

Сгенерировать секрет сессии локально можно командой `node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"`. Укажите одинаковое значение на всех экземплярах сервера. Имя администратора остаётся `admin`; если ADMIN_PASSWORD пуст, продолжает действовать существующий пароль. Для публичного запуска задайте свой пароль.

Перезапустите `npm run dev`. Для размещённого сайта задайте те же переменные в панели хостинга и заново соберите/разверните приложение. После смены секрета сессии войдите в админку заново.

## 4. Перенести существующие объявления

Откройте админку **именно в браузере и по тому адресу, где добавляли машины**. `localhost` и `127.0.0.1`, разные порты и разные профили браузера имеют отдельные хранилища.

1. **Настройки → Хранение данных**: дождитесь сообщения о подключении.
2. **Подготовить импорт из браузера**: проверьте список и количество автомобилей.
3. При необходимости отметьте замену контактов — по умолчанию они не перезаписываются.
4. **Начать импорт**. Держите вкладку открытой до завершения.

Локальные фото/видео загружаются в Storage; внешние ссылки остаются ссылками. Если локальный файл отсутствует или превышает облачный лимит, импорт останавливается с ошибкой. Уже перенесённые машины сохраняются, повторный запуск их пропустит. Совпадающие ID не перезаписываются. Локальные оригиналы не удаляются.

После включения Supabase пустая база показывает пустой каталог — демонстрационные автомобили автоматически не подставляются. При недоступности базы приложение показывает ошибку, а не переключается незаметно на localStorage.

## 5. Проверить работу

Откройте сайт на другом устройстве/в другом профиле браузера. Создайте автомобиль, заполните RU/CN, загрузите фото/видео, измените цену и контакты. Проверьте сохранение после перезагрузки и удаление тестовой машины. В открытых вкладках данные обновляются при возврате к вкладке и каждые 30 секунд; вкладки одного браузера дополнительно уведомляют друг друга об изменениях.

Медиа загружается непосредственно по подписанному URL, поэтому крупный файл не проходит через ограничения размера запросов Next.js/хостинга. Серверный ключ остаётся на сервере. Объекты имеют случайные имена и не перезаписываются.

Удаление объявления удаляет запись из каталога. Облачные медиа не удаляются автоматически, чтобы не повредить ссылки других объявлений. Неиспользуемые файлы, в том числе после прерванных загрузок, пока очищаются вручную в Storage после проверки ссылок. Не удаляйте файлы действующих объявлений.

Переводы хранятся на двух языках. Автоматический перевод — отдельное подключение и этим изменением не добавляется.
