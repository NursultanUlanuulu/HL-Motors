# firstseven-auto.com — запуск

Обновлено 17 октября 2026 года. Сайт доступен по HTTPS:
https://firstseven-auto.com и https://www.firstseven-auto.com.

## Рабочая инфраструктура

- DigitalOcean `hl-motors-production`, ID 609912502, IP `152.42.164.8`.
  Singapore SGP1, Ubuntu 24.04, 2 vCPU / 4 ГБ / 80 ГБ, $24/месяц.
- Docker Compose: PostgreSQL 16, Next.js 16.3.8 и Caddy с действующим
  HTTPS-сертификатом и автоматическим продлением. Данные PostgreSQL — в томе
  `hl-motors_database`. Не выполнять `docker compose down -v`.
- Порты базы и приложения наружу не опубликованы. Вход SSH — по ключу;
  парольный вход выключен. UFW разрешает SSH, HTTP и HTTPS. Swap — 2 ГБ.
- Миграции выполнены. Приложение использует отдельную ограниченную роль `hl_app`.
  Каталог пустой по выбору владельца. Демо-данные не переносились. Временная
  тестовая карточка после проверки удалена.
- Cloudflare R2 Standard/APAC: `hl-motors-media`, публичный адрес
  `https://media.firstseven-auto.com`, статус Active. CORS разрешает GET/HEAD/PUT
  с root/www сайта. Dev URL выключен. Ключ приложения ограничен этим бакетом.
- GoDaddy использует `lex.ns.cloudflare.com` и `zainab.ns.cloudflare.com`.
  Cloudflare A-запись root — `152.42.164.8`, www — CNAME root. Оба DNS-only;
  Caddy устанавливает доверенный заголовок IP. При включении Cloudflare proxy
  потребуется отдельная настройка доверенных прокси.
- Существующие SPF, DMARC, оба DKIM, `_acme-challenge` и `_domainconnect`
  сохранены. Исходных MX-записей не было.

- Локальные копии секретов и SSH-ключ защищены правами Windows; их значения
  не публиковать. Существующий сильный пароль администратора сохранён.
- Инструкции обновления: `deploy/README.md`. Архив исходников собирается
  `deploy/package-release.ps1`, включая оба корневых CSS-файла.

  не удалялись. Локальный демонстрационный каталог сохранён отдельно.
