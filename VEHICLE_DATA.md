# Справочники автомобилей и три языка

Интегрированы выбранные разделы исследования AutoHaina: поля объявления, краткие характеристики, марки и расширенные фильтры. Полные 348 технических параметров не добавлялись.

## Справочники

`lib/vehicle-dictionaries.ts` содержит все 628 исходных записей марок. Пять служебных `Date Fallback Make` недоступны для выбора. Один точный повтор названия объединён в интерфейсе: 622 уникальных названия, плюс сохранённые марки старых объявлений. Китайские названия сопоставлены по идентификатору исходного справочника. Общепринятые написания Li Auto, Mercedes-Benz, AITO и Geely отображаются вместо буквального машинного перевода источника.

Все 162 исходных значения фильтров сохранены в `sources`. После объединения трёх синонимов — 159 вариантов, включая два состояния. `Plug-in hybrid`/`plug-in hybrid`, `SUV/SUV`/`SUV` и два названия тройной литиевой батареи используют общие ключи. Идентификаторы рассчитываются из группы и исходного значения, независимо от порядка записей и языка.

Справочники находятся в проекте; работа сайта не зависит от доступности AutoHaina. Генератор `scripts/build-vehicle-dictionaries.py` использует сохранённые снимки в `output/autohaina`. Исходные машинные названия редких марок сохранены для сопоставления; это не подтверждение наличия этих машин в продаже.

## Добавление и перевод

- Марку, состояние, топливо, коробку, привод, кузов/класс, цвет, места, батарею, наддув и метки выбирают один раз. Подписи меняются между RU, EN и 中文.
- Пробег, мощность, объём, разгон, расход, ёмкость батареи, запас хода и цены хранятся числами. Пустое значение означает отсутствие данных; ноль сохраняется как ноль.
- Модель, комплектация, заголовок, город, текст двигателя, описание, преимущества и SEO-тексты имеют отдельные языковые поля. В форме доступны три вкладки.
- Свободный текст автоматически не переводится. Если нужного перевода нет, отображается доступный текст: запрошенный язык → русский → английский → китайский → прежнее поле.
- Характеристики в `specs` и метки в `featureTags` используют постоянные ключи. Цена продажи и FOB — USD, цена производителя — CNY; интерфейс явно указывает валюты.
- Прежние текстовые характеристики сохранены. Известные значения сопоставляются со справочниками при чтении; неизвестные не переписываются. Выбранные новые характеристики имеют приоритет при отображении.

Главная страница и каталог фильтруют по всем выбранным категориям, цене, году, пробегу и мощности. Поиск учитывает тексты всех языков. Смена языка не меняет выбранные фильтры. Полная карточка показывает заполненные характеристики, метки и переведённые описания.

Переключатель языка сохраняется в браузере. Языковые URL и отдельная серверная SEO-индексация по языкам не реализованы; метаданные карточки обновляются после загрузки её данных.

## База и запуск

Фильтр «Модель» показывает модели из объявлений выбранной марки; при смене марки выбранная модель сбрасывается. Названия моделей переводятся из полей карточек. Полный независимый справочник моделей AutoHaina не импортирован: исходный импорт включал справочник марок.

Для просмотра пяти демонстрационных машин: `npm run build`, затем `node scripts/demo-preview.cjs`. Каталог открывается по адресу `http://localhost:3107/catalog`. Данные находятся в `fixtures/demo-cars.json`; цены и статусы условные, фото требуют подключения к серверу AutoHaina. Используется отдельная временная локальная база, изменения исчезают после остановки. Настройки рабочей Supabase не меняются. Для повторного создания файла из сохранённых снимков: `node scripts/build-demo-cars.cjs`.

Перед запуском обновлённого редактора в существующей Supabase необходимо выполнить `supabase/migrations/202610150001_vehicle_dictionaries.sql` после прежних миграций. Она расширяет существующую проверку JSON и не переписывает объявления. Настоящая удалённая база в ходе этой работы не изменялась.

Валидация приложения и PostgreSQL проверяет новые поля, языки, допустимые ключи справочников, числовые границы и даты. Посторонние поля и неизвестные идентификаторы отклоняются.

## Интерфейс маркетплейса

Главная и `/catalog` открывают один каталог без рекламного первого экрана. Фильтры и сортировка хранятся в URL, карточка возвращает к тем же результатам. Топливо и состояние допускают несколько выбранных значений. Пагинация показывает по 12 автомобилей; счётчик и количество страниц вычисляются из данных.

Избранное доступно по `/favorites` и сохраняется в localStorage текущего браузера, синхронизируется между вкладками. Вход не нужен; между устройствами список не переносится. Корзины и сравнения нет. Маркетплейс оформлен отдельно от административного интерфейса в `marketplace.css`.

Доставка и оплата, о компании и контакты доступны на `/delivery`, `/about`, `/contacts`. На телефоне фильтры открываются в модальной панели с закрытием по Escape, на странице автомобиля закреплена кнопка связи.

`node tests/demo-browser.cjs` — проверка нового интерфейса на запущенном демокаталоге: поиск, фильтры, URL, избранное, три языка, страницы, мобильная версия и вход в админку. Тест не меняет автомобили; для проверки пагинации подменяет только ответ в тестовом браузере.

## Поиск и фотографии

Марки, модели и длинные списки характеристик имеют поиск внутри выпадающего списка. Поиск учитывает названия на трёх языках, а для распространённых марок — русские написания. Пробелы и дефисы не мешают искать модель. В списках марок и моделей показано количество объявлений; марки с объявлениями идут первыми. Списки поддерживают клавиатуру, закрытие по Escape и открываются поверх мобильных фильтров и редактора. Модели по-прежнему берутся из объявлений, а не из отдельного полного справочника.

Фотографии карточек, миниатюр и галереи проходят через оптимизатор Next.js: размер подбирается под экран, результат сохраняется в серверном кеше. Первые три карточки загружаются сразу, остальные — по мере прокрутки. Разрешены фото AutoHaina, Unsplash и публичного бакета `vehicle-media` собственного проекта Supabase. Публичный адрес хранилища определяется из `SUPABASE_URL` при сборке; после смены проекта нужна новая сборка. Остальные адреса и локальные загруженные файлы отображаются напрямую. При ошибке оптимизации выполняется попытка загрузить оригинал, затем показывается заглушка. Первое обращение к внешнему фото всё ещё зависит от доступности источника; перенос фото в собственное хранилище не выполнялся.

Галерея поддерживает полноэкранный просмотр, увеличение 2×, перетаскивание увеличенного фото, стрелки клавиатуры и свайпы. Миниатюры загружаются отдельно в небольшом размере. Видео открывается в той же модальной области.

`node tests/marketplace-media-browser.cjs` — проверка поиска, клавиатуры, мобильных списков, оптимизированных фото, галереи и выбора характеристик в админке на запущенном демокаталоге; записи не изменяются.

## Команды проверки

`npm test` — регрессионные проверки, включая сохранение трёх языков, фильтрацию и выполнение миграции в PGlite.

`npm run build` — проверка типов и production-сборка.

`node tests/security-preview.cjs`, затем `node tests/vehicle-dictionaries-browser.cjs` — браузерная проверка в изолированном каталоге с тестовыми автомобилями. Используется установленный Edge в headless-режиме. Проверка не обращается к рабочей базе и не загружает файлы в реальное хранилище.
